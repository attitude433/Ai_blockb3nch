## 오류 및 발견 사항

### 1. ashfox `set_frame_pose` — 일부 본에만 적용되는 버그
- **증상**: API 응답은 `bones=12` 성공으로 반환, 실제 Blockbench 타임라인에는 일부 본(오른 다리 계열)만 키프레임 표시
- **확인**: 익스포트된 model.animation.json에 forearm_r 하나만 들어가 있음
- **원인**: ashfox 0.0.4의 `set_frame_pose` 내부 버그 — Blockbench 내부 상태와 ashfox 내부 상태가 불일치
- **해결**: set_frame_pose 포기 → **GeckoLib 애니메이션 JSON 직접 작성**으로 우회
- **파일 위치**: `animations/` 폴더에 `{모델명}_{동작}.animation.json` 형식으로 저장

### 2. `set_frame_pose` — `frame` 파라미터가 초(s)가 아닌 프레임 번호
- **증상**: `frame=0.25`를 넣었더니 t=0.0125s 위치에 키프레임이 생성됨
- **원인**: `frame`은 프레임 인덱스 값. 실제 시간 = frame / snapping
- **공식**: `fps=20` 지정 시 snapping=20 → 0.25s = frame 5, 0.5s = frame 10, 0.75s = frame 15
- **해결**: 올바른 프레임 번호 사용 (결국 JSON 직접 작성으로 전환하여 무관)

### 3. GeckoLib 애니메이션 JSON — 회전값 부호 반전
- **증상**: set_frame_pose에 [25,0,0]을 넣었는데 익스포트 파일에는 [-25,0,0]으로 나옴
- **원인**: GeckoLib 애니메이션 JSON은 Blockbench 내부 회전값을 부호 반전해서 저장
- **규칙**: JSON 직접 작성 시 Blockbench 기준값의 부호를 반전해서 입력
- **확인**: forearm_r 기존 익스포트값과 대조하여 검증

### 4. `Load Animation File` — 키프레임 임포트 불가
- **증상**: giant_walk.animation.json을 Blockbench에 로드했더니 "new"라는 빈 애니메이션만 생성됨
- **원인**: GeckoLib 플러그인의 Load Animation File은 키프레임을 임포트하는 기능이 아님 — 저장 경로를 연결하는 기능
- **결론**: Blockbench에서 JSON 파일로 애니메이션 키프레임을 임포트하는 방법 없음. JSON 파일은 게임 리소스에 직접 사용

### 5. 루프 애니메이션 시작·끝 연결 끊김
- **증상**: t=0.75 → t=0 루프 경계에서 모션이 튐
- **원인**: catmullrom 보간 시 t=1.0 키프레임이 없으면 루프 경계 탄젠트 계산 불가
- **해결**: 모든 본에 t=1.0 키프레임을 t=0과 동일한 값으로 추가 → 매끄러운 루프 완성

## 확립된 애니메이션 워크플로우

### 파일 작성 규칙
```json
{
    "format_version": "1.8.0",
    "animations": {
        "animation.{모델명}.{동작}": {
            "loop": true,
            "animation_length": 1,
            "bones": {
                "bone_name": {
                    "rotation": {
                        "0.0":  { "post": { "vector": [x, y, z] }, "lerp_mode": "catmullrom" },
                        "0.25": { "post": { "vector": [x, y, z] }, "lerp_mode": "catmullrom" },
                        "0.5":  { "post": { "vector": [x, y, z] }, "lerp_mode": "catmullrom" },
                        "0.75": { "post": { "vector": [x, y, z] }, "lerp_mode": "catmullrom" },
                        "1.0":  { "post": { "vector": [x, y, z] }, "lerp_mode": "catmullrom" }
                    }
                }
            }
        }
    }
}
```

### 핵심 규칙
1. **set_frame_pose 사용 금지** — ashfox 0.0.4 버그로 일부 본만 적용됨
2. **JSON 직접 작성** → `animations/{모델명}_{동작}.animation.json`에 저장
3. **회전값 부호 반전** — Blockbench 기준값의 부호를 뒤집어서 입력
4. **t=1.0 키프레임 필수** — t=0과 동일한 값으로 추가해야 루프 연결
5. **애니메이션 이름** — `animation.{모델명}.{동작}` 형식 (GeckoLib 규칙)
6. **저장 위치** — `animations/` 폴더
