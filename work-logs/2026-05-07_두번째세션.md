## 오류 및 발견 사항

### 1. MCP 큐브 생성 시 텍스처 자동 바인딩 없음
- **증상**: 큐브 생성 후 렌더 시 완전히 투명
- **원인**: Blockbench UI는 큐브 생성 시 텍스처 자동 할당, MCP API는 그 단계 없음
- **해결**: assign_texture → paint_faces 페인팅 필수 (단색이라도)
- **다음부터**: 큐브 추가 직후 assign_texture + paint_faces 단계 포함

### 2. UV 좌표 겹침으로 일부 면 투명
- **증상**: paint_faces 후에도 일부 면이 투명하게 보임
- **원인**: 모든 큐브가 uvOffset=(0,0)으로 생성되어 UV 공간 공유. 일부 face가 unpainted 영역에 매핑됨
- **해결**: 모든 큐브의 모든 face(north/south/east/west/up/down)를 명시적으로 순서대로 페인팅
  ```powershell
  foreach ($cube in $allCubes) {
      foreach ($face in @("north","south","east","west","up","down")) {
          Invoke-Mcp "paint_faces" @{ target=@{ cubeName=$cube; face=$face }; ... }
      }
  }
  ```
- **핵심**: revision이 큐브마다 다르게 갱신되어야 정상 (같은 revision = 이전 호출 실패)

### 3. update_cube 후 UV 재배치로 투명 재발
- **증상**: Z 깊이 수정(update_cube) 후 새 UV 영역이 unpainted 상태로 생성됨
- **원인**: update_cube가 내부 UV 아틀라스를 재배치하며 새 영역 추가
- **해결**: update_cube 후 반드시 해당 큐브 재페인팅 (face별로 명시)
- **주의**: 재페인팅 루프에서 revision이 호출마다 갱신되는지 확인. 같은 revision 연속 = 실패

### 4. render_preview 카메라 뷰 틀어짐
- **증상**: 156회 페인팅 후 카메라가 탑뷰(위에서 내려다보기)로 고정됨
- **원인**: Blockbench 내부 뷰포트 상태가 변경되며 render_preview 카메라도 영향받는 것으로 추정
- **해결책**: Blockbench 뷰포트에서 직접 확인, 또는 카메라 리셋 후 렌더

### 5. 지오메트리 갭 (투명처럼 보이는 실제 구멍)
- **증상**: 가슴(Z ±9)과 팔(초기 Z ±5) 깊이 불일치로 어깨 경계에 구멍
- **해결**: update_cube로 팔/다리 Z 깊이를 인접 몸통 큐브에 맞춤
- **원칙**: 접하는 큐브들의 같은 축 범위는 일치시킬 것
